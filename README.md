EMBERLINE — Kestrel Yard: a 4v4 round-based tactical FPS in a dusk solar yard. Ember defends the Reactor against Ashfall bots — rounds, an economy and buy menu, bomb plant and defuse, first to 3 rounds takes the match. Bots route a waypoint graph, fight in bursts with human-like reaction times, and push the objective: the Ashfall carrier plants the charge, Ember defuses it or wipes the attackers out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
